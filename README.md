# Agency Landing Page Template

Clean, responsive HTML/CSS landing page template for agencies and freelancers.

## What's included
- Sticky frosted glass navbar
- Hero section
- Pricing cards with featured highlight
- Footer
- Mobile responsive layout

## How to use
1. Open `index.html` in any browser
2. Edit text content directly in the HTML
3. Change colors by editing `--primary-color` in the `:root` section
4. Replace the hero image URL with your own
